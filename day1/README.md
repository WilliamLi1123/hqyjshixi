# 实习总结

经过第一天的实习，我学到了以下内容：

## 1. 环境准备
- 学会了如何检查 Python 版本，如何创建和激活虚拟环境，如何安装第三方库（如 `requests`）。

## 2. 变量、数据类型与作用域
- 学到了 Python 中的基本数据类型：`int`、`float`、`str`、`bool`、`list`、`tuple`、`dict`、`set` 等，并掌握了如何进行类型转换。
- 还学习了作用域的概念，包括全局变量和局部变量，如何使用 `global` 和 `nonlocal` 关键字。

## 3. 运算符与表达式
- 学习了常用的 Python 运算符，包括算术运算符、比较运算符、逻辑运算符和位运算符。
- 能编写更高效和功能丰富的 Python 代码。

## 4. 控制流语句
- 学会了如何使用条件语句（`if`、`elif`、`else`）、循环语句（`for`、`while`）以及异常处理语句（`try`、`except`、`finally`）。

## 5. 函数的定义与使用
- 学习了函数的定义与使用，如何使用默认参数、可变参数以及高阶函数（函数作为参数传递）。

## 6. 模块与包
- 学习了如何定义和导入模块、如何创建包。通过这些，你能将代码组织成模块和包，提高代码的可维护性和复用性。

## 7. 面向对象编程
- 学习了面向对象编程如何定义类、创建对象、使用继承、多态和封装等面向对象编程的核心概念。

## 8. 装饰器
- 了解了装饰器的基本概念，以及如何使用它来修改函数的行为。这能帮助你理解更高级的 Python 编程技巧。

## 9. 文件操作
- 学习了如何读写文本文件，如何使用 `with` 语句来自动管理文件资源，确保文件的正确关闭。
- 学习了如何处理 CSV 和 JSON 文件，这对于数据处理和存储非常重要。

## 10. Git命令
- 通过笔记中包括的常用 Git 命令，如 `git init`、`git add`、`git commit`、`git push` 等，帮助你理解 Git 的基本操作。
