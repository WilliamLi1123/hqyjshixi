## 1. 简介

| 项目 | YOLOv8 | YOLOv12 |
|------|--------|---------|
| 发布时间 | 2023年1月 | 2025年上半年（Ultralytics 推出） |
| 框架支持 | PyTorch | PyTorch + ONNX + TensorRT |
| 主要特性 | Anchor-free 架构、模块化设计 | 引入 Vision Mamba、动态路径优化、语义引导解码器 |
| 开发维护 | Ultralytics 官方 | Ultralytics 官方 |

---

## 2. 架构比较

| 模块 | YOLOv8 | YOLOv12 |
|------|--------|---------|
| 主干网络 (Backbone) | CSPDarknet 替代结构 | Mamba-based Encoder + Efficient RepNeXt |
| 颈部网络 (Neck) | PAN-FPN 改进版 | DPFNeck（Dynamic Path Feature Fusion） |
| 检测头 | 单层解码器，支持分类/检测/分割多任务 | SGHead（Semantic-Guided Head） |
| Anchor 策略 | Anchor-Free | Anchor-Free（支持 Dense Head 和 Dynamic Head） |

**YOLOv12 新增特点：**
- 使用了 Mamba 高效序列建模结构替代传统 CNN 部分。
- 支持 **视觉大模型微调** 和多尺度全局语义融合。
- 模型组件更加解耦，易于插拔扩展。

---

## 3. 训练策略对比

| 项目 | YOLOv8 | YOLOv12 |
|------|--------|---------|
| 自动混合精度 (AMP) | ✅ 支持 | ✅ 支持 |
| EMA 滑动平均 | ✅ 默认启用 | ✅ 增强版，支持滑动窗口控制 |
| 数据增强 | Mosaic、MixUp、HSV、翻转 | 添加 AutoAugment、ViT风格 PatchMix |
| 损失函数 | CIoU + BCE Loss | SIoU v3 + Varifocal Loss |
| 优化器 | SGD / AdamW 可选 | 默认 AdamW + OneCycleLR |

---

## 4. 性能差异

| 指标 | YOLOv8-n | YOLOv12-n | YOLOv8-l | YOLOv12-l |
|------|----------|-----------|----------|-----------|
| 参数量 | ~6.2M | ~7.1M | ~43.7M | ~45.5M |
| FPS (GPU) | 170+ | 180+ | 65+ | 72+ |
| mAP@0.5 | 50.2% | 52.8% | 56.8% | 59.5% |
| mAP@0.5:0.95 | 33.6% | 36.2% | 45.2% | 47.9% |

> YOLOv12 在保持轻量化的同时，提升了 2~3% 的准确率，推理速度略快，适用于更复杂任务场景。

---

## 5. 推理优化

| 特性 | YOLOv8 | YOLOv12 |
|------|--------|---------|
| TensorRT 支持 | ✅ | ✅（动态 Batch + INT8 更稳定） |
| ONNX 导出 | ✅ | ✅（兼容性更强） |
| TTA（测试时增强） | ✅ 可选 | ✅ 默认集成 |
| 动态输入 | ⚠️ 需要手动处理 | ✅ 自动支持 |
| 多任务推理（Det+Seg） | ✅ | ✅ 效果更好，融合更高效 |

---

## 6. 应用场景

| 场景 | 推荐版本 |
|------|----------|
| 嵌入式部署 / 移动端 | YOLOv8-n / YOLOv12-n |
| 自动驾驶 / 安防 | YOLOv12-m/l |
| 多任务检测（目标+分割） | YOLOv12 优先 |
| 精度优先任务（如工业检测） | YOLOv12-l |
| 教学/入门/快速部署 | YOLOv8 |

---

## 7. 总结

| 项目 | YOLOv8 | YOLOv12 |
|------|--------|---------|
| 模型稳定性 | ✅ 高 | ✅ 更高 |
| 精度表现 | ✅ 优秀 | 🔥 更优 |
| 易用性 | ✅ 官方 CLI 支持 | ✅ CLI + API 更丰富 |
| 部署效率 | ✅ 快速部署 | ✅ 支持自动图优化 |

**结论：**

- 如果追求 **成熟稳定、部署快速**，YOLOv8 是目前成熟选择；
- 如果追求 **更高精度、更强表达力**，尤其在复杂任务中，YOLOv12 更具前瞻性和扩展性。
