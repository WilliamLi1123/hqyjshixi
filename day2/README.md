# PyTorch 深度学习项目学习要点

## 一、PyTorch 基础
1. **张量操作**
   -（`convolutionalNeuralNetwork.py`）：创建和操作张量，包括形状变换（`torch.reshape`）和卷积操作（`F.conv2d`）。
2. **数据加载与预处理**
   - 使用 `torchvision.datasets` 和 `DataLoader` 加载 CIFAR10 数据集并转换为张量。
   - 对单张图片进行预处理（调整大小、转换为张量等）。

## 二、卷积神经网络（CNN）构建
1. **模型定义**
   - 定义简单 CNN 模型，包括卷积层、池化层、全连接层等。
   - 定义单卷积层模型，展示卷积层输出效果。
2. **前向传播**
   - 在模型类中通过 `forward` 方法定义数据传播路径。

## 三、模型训练
1. **训练流程**
   - 完整训练流程，包括数据加载、前向传播、损失计算、反向传播、参数更新、日志记录。
2. **GPU 加速**
   - 将模型和数据移动到 GPU 上加速训练。
3. **超参数设置**
   - 设置学习率、训练轮数、批量大小等超参数，保存模型。

## 四、模型测试与评估
1. **测试流程**
   - 每个训练轮数结束后对模型进行测试，计算测试集损失和正确率。
2. **模型加载与推理**
   - 加载训练好的模型，对单张图片进行推理。

## 五、TensorBoard 使用
1. **日志记录与可视化**
   - 使用 `SummaryWriter` 记录训练和测试指标，保存日志文件，通过 TensorBoard 可视化分析。

## 六、代码组织与模块化
1. **模块化设计**
   - 将模型定义单独放在 `model.py` 文件中，其他文件导入使用。
2. **主函数与脚本运行**
   - 使用 `if __name__ == '__main__':` 定义主函数，方便直接运行脚本测试。

## 七、实践与调试技巧
1. **调试信息打印**
   - 打印数据集长度、张量形状、训练损失等信息，帮助了解程序运行状态。
2. **错误处理与优化**
   - 实际运行代码时，积累处理常见问题（如张量形状不匹配、GPU 内存不足）的经验，优化代码性能和稳定性。
