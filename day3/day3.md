# 学习内容总结

## 一、模型训练与验证

### 1. PyTorch 模型训练流程
- 设置训练设备（如 GPU）
- 标准化图像输入
- 加载数据集
- 定义模型结构
- 配置损失函数和优化器
- 实现训练和验证循环，完成完整的训练流程

### 2. 迁移学习的应用
- 加载预训练的 ResNet18 模型
- 替换分类头（如更改 `fc` 层）
- 利用预训练模型快速构建适用于特定任务的模型

### 3.图像预处理
- 标准化图像输入

### 4. 数据预处理与数据加载
- 使用 `torchvision.transforms` 进行图像的预处理操作（如Resize、ToTensor、Normalize等）
- 使用 `DataLoader` 加载数据集，支持批量读取、打乱顺序、并行加速等

### 5. TensorBoard 的使用
- 使用 `SummaryWriter` 记录训练与验证过程中的指标（如 loss 和 accuracy）
- 使用 TensorBoard 进行训练过程的可视化分析与调优

### 6. 模型保存策略
- 每轮训练保存当前模型权重
- 根据验证准确率判断是否保存“最优模型”
- 确保关键模型在训练过程中得到保留
